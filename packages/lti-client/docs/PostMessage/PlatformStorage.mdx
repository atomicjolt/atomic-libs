# PlatformStorage

`PlatformStorage` reads and writes key/value data stored by the LMS, as defined by the
[LTI Client Side postMessage Storage](https://www.imsglobal.org/spec/lti-pm-s/v0p1) spec
(`lti.get_data` / `lti.put_data`). It's useful when the browser blocks your tool's own cookies and
storage inside the LMS iframe.

## Setup

```ts
import { PostMessageClient, PlatformStorage } from "@atomicjolt/lti-client";

const client = new PostMessageClient({ origin: "https://canvas.instructure.com" });
const storage = new PlatformStorage(client);
```

The client argument is optional; without it a `PostMessageClient` with default options (origin `"*"`) is created.

## Methods

| Method | Description |
| --- | --- |
| `isSupported(): Promise<boolean>` | `true` if the platform's capabilities include both `lti.get_data` and `lti.put_data`. |
| `get(key): Promise<string \| null>` | The stored value, or `null` if the platform reports `key_not_found`. |
| `set(key, value): Promise<void>` | Stores `value` under `key`. |
| `remove(key): Promise<void>` | Removes `key` (sends `lti.put_data` with `value: null`). |

Values come back as strings, so serialize anything else yourself.

## Example

```ts
if (!(await storage.isSupported())) {
  console.warn("Platform storage isn't available");
} else {
  await storage.set("settings", JSON.stringify({ theme: "dark" }));

  const stored = await storage.get("settings");
  const settings = stored === null ? {} : JSON.parse(stored);

  await storage.remove("settings");
}
```

## Errors

Every method rejects with a [`PostMessageError`](./PostMessageClient.mdx#errors) on a timeout or an
error response (other than `key_not_found` from `get`, which resolves `null`).

```ts
import { PostMessageError } from "@atomicjolt/lti-client";

try {
  await storage.set("my-key", "my-value");
} catch (error) {
  if (error instanceof PostMessageError && error.response?.error?.code === "storage_full") {
    console.error("Platform storage is full");
  } else {
    console.error("Storage operation failed:", error);
  }
}
```
