# ResizeIframe

`ResizeIframe` asks the platform to change the height of the iframe your tool is running in, using the
`lti.frameResize` postMessage. Canvas and Brightspace support it; check `isSupported()` on other platforms.

:::tip
In a React app, [`@atomicjolt/canvas-client`](/canvas-client/ResizeHandling)'s `ResizeIframe` component
watches the page and calls this class for you whenever the content height changes.
:::

## Setup

```ts
import { PostMessageClient, ResizeIframe } from "@atomicjolt/lti-client";

const client = new PostMessageClient({ origin: "https://platform.example.com" });
const resizer = new ResizeIframe(client);
```

The client argument is optional; without it a `PostMessageClient` with default options is created.

## Methods

| Method | Description |
| --- | --- |
| `isSupported(): Promise<boolean>` | `true` if the platform's capabilities include `lti.frameResize`. |
| `resize(height: number): Promise<void>` | Requests a frame height, in pixels. |

`resize` waits for the platform's `lti.frameResize.response` like any other
[`send`](./PostMessageClient.mdx#send), so it rejects with a timeout `PostMessageError` if the platform
applies the resize without replying. Catch the error if you don't need confirmation.

## Examples

Resize once after content loads:

```ts
if (await resizer.isSupported()) {
  await loadContent();
  await resizer.resize(document.documentElement.scrollHeight);
}
```

Keep the frame sized to the page:

```ts
const observer = new ResizeObserver(() => {
  resizer.resize(document.documentElement.scrollHeight).catch(() => {});
});

observer.observe(document.body);
```
