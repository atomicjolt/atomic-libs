# Authentication

## `CanvasAuthenticationForm`

Renders a `<form method="post">` that sends the user to your server's Canvas OAuth endpoint. Each entry
in `settings` becomes a hidden input, so the server receives whatever it needs to resume the launch
(for example the launch state or a token). Use it with `autoSubmit` to redirect immediately, or with your
own submit button to explain why the user is being sent to Canvas first.

```tsx
import { CanvasAuthenticationForm } from "@atomicjolt/canvas-client";

function AuthorizeCanvas({ launchToken }: { launchToken: string }) {
  return (
    <CanvasAuthenticationForm
      action="/canvas/oauth/start"
      settings={{ launch_token: launchToken, return_to: "/dashboard" }}
      autoSubmit
    />
  );
}
```

This renders, and submits on mount:

```html
<form action="/canvas/oauth/start" method="post">
  <input type="hidden" name="launch_token" value="…" />
  <input type="hidden" name="return_to" value="/dashboard" />
</form>
```

### Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `action` | `string` | | URL the form posts to. Required. |
| `settings` | `Record<string, any>` | `{}` | One hidden input per entry. Object and array values are JSON-encoded. |
| `autoSubmit` | `boolean` | `false` | Submit the form as soon as it mounts. |
| `children` | `ReactNode` | | Rendered inside the form, after the hidden inputs (e.g. a submit button). |

Any other `<form>` attribute (`target`, `className`, `method`, ...) is passed through to the form element.

### Asking before redirecting

Leave `autoSubmit` off and put a submit button inside the form:

```tsx
import { CanvasAuthenticationForm } from "@atomicjolt/canvas-client";

function AuthorizePrompt({ launchToken }: { launchToken: string }) {
  return (
    <div>
      <h1>Connect to Canvas</h1>
      <p>This tool needs permission to read your courses. You'll come straight back here afterwards.</p>
      <CanvasAuthenticationForm action="/canvas/oauth/start" settings={{ launch_token: launchToken }}>
        <button type="submit">Authorize</button>
      </CanvasAuthenticationForm>
    </div>
  );
}
```
