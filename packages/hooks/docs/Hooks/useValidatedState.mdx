# `useValidatedState`

A `useState` wrapper that runs every new value through a validator before storing it. Invalid values
are rejected (the state keeps its previous value) and the validator's result is stored as the error.

```ts
function useValidatedState<T, E = string>(
  initialState: T,
  validator: (newState: T) => void | E
): [state: T, error: E | null, setState: Dispatch<SetStateAction<T>>];
```

## Parameters

- `initialState`: the initial value. It is **not** validated.
- `validator`: called with each new value. Return nothing (or any falsy value) to accept it; return an
  error (a message string by default, or any type `E`) to reject it.

## Returns

- `state`: the last accepted value.
- `error`: the most recent validation error, or `null` if no update has been rejected yet.
- `setState`: accepts a value or an updater function. Updater functions are resolved before validation.

## Example

```tsx
import { useValidatedState } from "@atomicjolt/hooks";

function Quantity() {
  const [quantity, error, setQuantity] = useValidatedState(1, (value) => {
    if (value < 1) return "Quantity must be at least 1";
  });

  return (
    <div>
      <button onClick={() => setQuantity((q) => q - 1)}>-</button>
      <span>{quantity}</span>
      <button onClick={() => setQuantity((q) => q + 1)}>+</button>
      {error && <p role="alert">{error}</p>}
    </div>
  );
}
```

:::caution
A later valid update does not clear `error`; once set, it stays until another rejected update replaces it.
Track validity separately if you need the error to disappear when the value becomes valid again.
:::
