# `useLocalStorage`

State that is also saved to `localStorage`. Setting the value writes it (JSON-encoded) under `key`; on
the next mount, a stored value for `key` is used instead of `initialState`, so it survives reloads.

```ts
function useLocalStorage<T>(
  key: string,
  initialState: T
): [state: T, setState: (value: T) => void, remove: () => void];
```

:::tip
To change how values are serialized, or to prefix keys, build your own hook with
[`makeStorageHook`](../Constructors/makeStorageHook.mdx).
:::

## Parameters

- `key`: the `localStorage` key.
- `initialState`: used when nothing is stored under `key`. It isn't written to storage until you call `setState`.

## Returns

- `state`: the current value.
- `setState`: sets the state and writes it to `localStorage`. It takes a value only, not an updater function.
- `remove`: deletes the key from `localStorage`. The value held in state is unchanged.

## Example

```tsx
import { useLocalStorage } from "@atomicjolt/hooks";

function SidebarToggle() {
  const [collapsed, setCollapsed, forget] = useLocalStorage("sidebarCollapsed", false);

  return (
    <div>
      <button onClick={() => setCollapsed(!collapsed)}>
        {collapsed ? "Expand" : "Collapse"} sidebar
      </button>
      <button onClick={forget}>Forget preference</button>
    </div>
  );
}
```

:::note
Values are read once, when the component mounts. Other components (or tabs) using the same key don't
update when the value changes.
:::
