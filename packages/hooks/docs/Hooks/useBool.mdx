# `useBool`

A `useState` wrapper for booleans that adds a stable `toggle` function. Handy for open/closed,
shown/hidden and on/off state.

```ts
function useBool(
  initialState?: boolean | (() => boolean)
): [value: boolean, toggle: () => void, set: Dispatch<SetStateAction<boolean>>];
```

## Parameters

- `initialState` (optional): the starting value, or a function that returns it. Defaults to `false`.

## Returns

- `value`: the current boolean.
- `toggle`: flips the value. Its identity is stable across renders, so it's safe to pass to memoized children.
- `set`: React's state setter; accepts a boolean or an updater function.

## Example

```tsx
import { useBool } from "@atomicjolt/hooks";

function Details() {
  const [isOpen, toggle, setOpen] = useBool();

  return (
    <div>
      <button onClick={toggle}>{isOpen ? "Hide" : "Show"} details</button>
      <button onClick={() => setOpen(false)}>Close</button>
      {isOpen && <p>Here are the details.</p>}
    </div>
  );
}
```
