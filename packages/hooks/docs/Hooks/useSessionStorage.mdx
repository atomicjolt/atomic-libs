# `useSessionStorage`

State that is also saved to `sessionStorage`. It works exactly like
[`useLocalStorage`](./useLocalStorage.mdx), but the value lasts only for the browser tab's session.

```ts
function useSessionStorage<T>(
  key: string,
  initialState: T
): [state: T, setState: (value: T) => void, remove: () => void];
```

:::tip
To change how values are serialized, or to prefix keys, build your own hook with
[`makeStorageHook`](../Constructors/makeStorageHook.mdx).
:::

## Parameters

- `key`: the `sessionStorage` key.
- `initialState`: used when nothing is stored under `key`.

## Returns

- `state`: the current value.
- `setState`: sets the state and writes it (JSON-encoded) to `sessionStorage`. Takes a value only, not an updater function.
- `remove`: deletes the key from `sessionStorage`. The value held in state is unchanged.

## Example

```tsx
import { useSessionStorage } from "@atomicjolt/hooks";

function DraftComment() {
  const [draft, setDraft, clearDraft] = useSessionStorage("commentDraft", "");

  return (
    <form
      onSubmit={(e) => {
        e.preventDefault();
        postComment(draft);
        setDraft("");
        clearDraft(); // after setDraft, which would write "" back to storage
      }}
    >
      <textarea value={draft} onChange={(e) => setDraft(e.target.value)} />
      <button type="submit">Post</button>
    </form>
  );
}
```
