# `useUnmount`

Runs `callback` when the component unmounts. Equivalent to `useEffect(() => callback, [])`.

```ts
function useUnmount(callback: () => void): void;
```

## Parameters

- `callback`: the function to run on unmount. It's captured on the first render, so it only sees the
  props and state from that render; read anything newer through a ref.

## Example

```tsx
import { useUnmount } from "@atomicjolt/hooks";

function Editor() {
  useUnmount(() => {
    console.log("Editor closed");
  });

  return <div>Editor</div>;
}
```
