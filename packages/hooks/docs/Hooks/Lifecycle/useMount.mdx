# `useMount`

Runs `callback` once, after the component's first render. Equivalent to `useEffect(callback, [])`.

```ts
function useMount(callback: EffectCallback): void;
```

## Parameters

- `callback`: the function to run. Like an effect, it may return a cleanup function, which runs when the
  component unmounts. It only sees the props and state from the first render.

## Example

```tsx
import { useMount } from "@atomicjolt/hooks";

function Page() {
  useMount(() => {
    analytics.track("page_viewed");
  });

  return <div>My page</div>;
}
```

:::note
In development under `<StrictMode>`, React mounts components twice, so the callback (and its cleanup)
runs twice.
:::
