# `useRender`

Runs `callback` after every render. Equivalent to `useEffect(callback)` with no dependency array.

```ts
function useRender(callback: EffectCallback): void;
```

## Parameters

- `callback`: the function to run after each render. It may return a cleanup function, which runs
  before the next call and on unmount.

## Example

```tsx
import { useRender } from "@atomicjolt/hooks";

function Chart({ data }: { data: number[] }) {
  useRender(() => {
    console.log("Chart rendered with", data.length, "points");
  });

  return <svg>{/* ... */}</svg>;
}
```
