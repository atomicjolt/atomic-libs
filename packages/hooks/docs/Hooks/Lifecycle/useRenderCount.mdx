# `useRenderCount`

Returns how many times the component has rendered **before** the current render: `0` on the first
render, `1` on the second, and so on. Mostly useful when debugging unexpected re-renders.

```ts
function useRenderCount(): number;
```

The count is kept in a ref and incremented in an effect, so it never causes a re-render itself.

## Example

```tsx
import { useRenderCount } from "@atomicjolt/hooks";

function Row({ item }: { item: Item }) {
  const renders = useRenderCount();
  console.log(`Row ${item.id} has rendered ${renders + 1} times`);

  return <li>{item.name}</li>;
}
```
