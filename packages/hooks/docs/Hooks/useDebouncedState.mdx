# `useDebouncedState`

Returns a debounced copy of a value that changes often (typically a prop or another piece of state). The
returned state only updates once `value` has stopped changing for `delay` milliseconds; each new `value`
restarts the timer.

```ts
function useDebouncedState<T>(
  value: T,
  delay: number
): [debounced: T | undefined, setDebounced: Dispatch<SetStateAction<T | undefined>>];
```

## Parameters

- `value`: the value to debounce. Pass the live value on every render.
- `delay`: how long `value` must stay unchanged, in milliseconds, before the debounced copy updates.

## Returns

- `debounced`: starts as the first `value`, then follows `value` after each `delay` of quiet.
- `setDebounced`: sets the debounced copy immediately, without waiting. The next change to `value` will
  overwrite it again after `delay`.

## Example

Search as the user types, but only query the API once they pause:

```tsx
import { useEffect, useState } from "react";
import { useDebouncedState } from "@atomicjolt/hooks";

function CourseSearch() {
  const [query, setQuery] = useState("");
  const [debouncedQuery] = useDebouncedState(query, 300);

  useEffect(() => {
    if (debouncedQuery) searchCourses(debouncedQuery);
  }, [debouncedQuery]);

  return <input value={query} onChange={(e) => setQuery(e.target.value)} />;
}
```
