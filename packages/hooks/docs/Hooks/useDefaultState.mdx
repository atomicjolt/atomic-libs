# `useDefaultState`

`useState` plus a `revert` function that resets the state to its initial value.

```ts
function useDefaultState<T>(
  initialState: T | (() => T)
): [state: T, setState: Dispatch<SetStateAction<T>>, revert: () => void];
```

## Parameters

- `initialState`: the initial value, or a function that returns it. Like `useState`, only the value from
  the first render is used; passing a different `initialState` later doesn't change what `revert` resets to.

## Returns

- `state`: the current value.
- `setState`: React's state setter; accepts a value or an updater function.
- `revert`: resets `state` to the initial value.

## Example

```tsx
import { useDefaultState } from "@atomicjolt/hooks";

function Filters() {
  const [filters, setFilters, resetFilters] = useDefaultState({ status: "all", query: "" });

  return (
    <div>
      <input
        value={filters.query}
        onChange={(e) => setFilters((f) => ({ ...f, query: e.target.value }))}
      />
      <button onClick={resetFilters}>Clear filters</button>
    </div>
  );
}
```
