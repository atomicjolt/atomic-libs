# `makeContext`

Creates a React context and returns its provider together with a hook that reads it, so you don't have
to export the context object itself.

```ts
function makeContext<T>(defaultValue: T): [Provider: React.Provider<T>, useValue: () => T];
```

## Parameters

- `defaultValue`: the value the hook returns when there's no provider above the component.

## Returns

- `Provider`: the context's `Provider`. Pass the current value with its `value` prop.
- `useValue`: a hook that returns the nearest provider's value (or `defaultValue`).

## Example

```tsx
import { makeContext } from "@atomicjolt/hooks";

type Theme = "light" | "dark";

export const [ThemeProvider, useTheme] = makeContext<Theme>("light");

function ThemedButton() {
  const theme = useTheme();
  return <button className={`btn-${theme}`}>Save</button>;
}

function App() {
  return (
    <ThemeProvider value="dark">
      <ThemedButton />
    </ThemeProvider>
  );
}
```
