# `makeStorageHook`

Builds a storage-backed state hook like [`useLocalStorage`](../Hooks/useLocalStorage.mdx) (which is
literally `makeStorageHook(localStorage)`). Use it to change how values are serialized, to namespace keys
with a prefix, or to back the hook with your own storage object.

```ts
function makeStorageHook<Stored = string>(
  storage: {
    getItem(key: string): Stored;
    setItem(key: string, value: Stored): void;
    removeItem(key: string): void;
  },
  options?: {
    prepare?: (value: any) => Stored; // default: JSON.stringify
    parse?: (stored: Stored) => any;  // default: JSON.parse
    prefix?: string;                  // default: ""
  }
): <T>(key: string, initialState: T) => [state: T, setState: (value: T) => void, remove: () => void];
```

## Parameters

- `storage`: anything with `getItem`, `setItem` and `removeItem`: `localStorage`, `sessionStorage`, or your own object.
- `options` (optional):
  - `prepare`: converts a value into what gets stored. Defaults to `JSON.stringify`.
  - `parse`: converts a stored value back. Defaults to `JSON.parse`.
  - `prefix`: prepended to every key, e.g. `"myApp:"`.

## Returns

A hook with the same signature as `useLocalStorage`: call it with a `key` and an `initialState`, and it
returns `[state, setState, remove]`. A stored value for the key is used instead of `initialState` when
the component mounts (falsy stored values such as `""` are ignored). `setState` takes a value only, not an
updater function. `remove` deletes the key from storage without changing the state.

## Examples

Namespace every key for your app:

```tsx
import { makeStorageHook } from "@atomicjolt/hooks";

const useAppStorage = makeStorageHook(localStorage, { prefix: "gradebook:" });

function ColumnPicker() {
  // Stored under "gradebook:columns"
  const [columns, setColumns] = useAppStorage("columns", ["name", "score"]);
  // ...
}
```

Store dates as ISO strings:

```tsx
const useDateStorage = makeStorageHook(localStorage, {
  prepare: (date: Date) => date.toISOString(),
  parse: (stored) => new Date(stored),
});

const [lastVisit, setLastVisit] = useDateStorage("lastVisit", new Date());
```

Back it with your own store (here, an in-memory `Map` that lasts until the page reloads):

```tsx
const memory = new Map<string, string>();

const useMemoryStorage = makeStorageHook({
  getItem: (key) => memory.get(key) ?? "",
  setItem: (key, value) => memory.set(key, value),
  removeItem: (key) => memory.delete(key),
});
```
