# Links and routing

Several components render as a link when you give them an `href`. They then accept the usual
anchor props (`href`, `target`, `rel`, `download`, ...) and keep their own styling.

| Component | With `href` |
| --- | --- |
| `Link` | An inline text link |
| `Button`, `IconButton` | A link styled as a button |
| `Tabs.Tab` | A tab that navigates (for tabs that map to routes) |
| `Item` in a `Menu` / `IconMenu` | A menu item that navigates |
| `Chip` | A chip that navigates |

    </Link>

`Button` renders an `<a>` whenever `href` is set. Use a link (`href`) for navigation and a button
(`onPress`) for actions; screen reader users hear the difference.

## Client-side routing

By default, links do a full browser navigation. If your app uses a client-side router, wrap it in
`RouterProvider` so every link above navigates through your router instead. `RouterProvider` takes:

- `navigate(path)`: your router's navigate function.
- `useHref(path)` (optional): converts a router path into a real URL for the `href` attribute, for
  example to add your router's base path.

With React Router, render it inside the router so its hooks are available:

```tsx
import { BrowserRouter, useHref, useNavigate } from "react-router-dom";
import { ElementsProvider, RouterProvider } from "@atomicjolt/atomic-elements";

function ElementsRouter({ children }: { children: React.ReactNode }) {
  const navigate = useNavigate();

  return (
    <RouterProvider navigate={navigate} useHref={useHref}>
      {children}
    </RouterProvider>
  );
}

export function Root() {
  return (
    <ElementsProvider applyDefaultStyles>
      <BrowserRouter>
        <ElementsRouter>
          <App />
        </ElementsRouter>
      </BrowserRouter>
    </ElementsProvider>
  );
}
```

Now `<Button href="/courses/42">` navigates without a page reload.

Links still use native browser navigation when:

- the `href` points to another origin,
- `target` is set to anything other than `"_self"`,
- `download` is set, or
- the user opens the link in a new tab or window (modifier-click, middle-click).

`RouterProvider` is React Aria's; see
[React Aria's routing guide](https://react-spectrum.adobe.com/react-aria/routing.html) for other
routers and for typing router options.
