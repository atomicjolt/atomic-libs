# Typography

Atomic Elements has a small set of typography components that draw their sizes, weights and colors
from the theme, so text stays consistent across an app.

| Component | Renders | Use for |
| --- | --- | --- |
| `Text` | `<span>` (or `div`, `p`, `label` via `as`) | Body text, captions, inline text |
| `Heading` | `<h1>` (or `h2`…`h6` via `as`) | Section headings |
| `Strong` | `<strong>` | Bold emphasis inside text |
| `Em` | `<em>` | Italic emphasis inside text |
| `Link` | `<a>` | Inline links (see [Routing](../Guides/Routing.mdx)) |

## Text and Heading

`Text` and `Heading` share the same style props:

| Prop | Values |
| --- | --- |
| `$size` | A scale step `"1"`…`"9"`, or any CSS font size |
| `$weight` | `"light"`, `"regular"`, `"medium"`, `"bold"` |
| `$color` | A color token (`"text-clr-secondary"`, `"accent-clr"`, ...) or any CSS color |
| `$align` | `"left"`, `"center"`, `"right"`, `"justify"` |
| `$transform` | `text-transform` values, e.g. `"uppercase"` |
| `$wrap` | `"nowrap"`, `"pretty"`, `"balanced"` |
| `$truncate` | Keep to one line and cut off with an ellipsis |
| `$clamp` | Cut off after this many lines, `"1"`…`"10"` |
| `$lineHeight`, `$letterSpacing` | A scale step or CSS value; overrides the one `$size` sets |
| `$decoration` | `text-decoration` value, e.g. `"underline"` |

They also accept margin props (`$m`, `$mt`, `$mb`, ...) and width/height props. See
[style props](../Guides/Layout.mdx#style-props).

<Example>
  <Example.Rendered>
    <Heading as="h2" $size="6">Course settings</Heading>
    <Text as="p" $color="text-clr-secondary">Changes apply to every section of this course.</Text>
  </Example.Rendered>
  <Example.Code>
    ```tsx
    <Heading as="h2" $size="6">Course settings</Heading>
    <Text as="p" $color="text-clr-secondary">
      Changes apply to every section of this course.
    </Text>
    ```
  </Example.Code>
</Example>

:::tip Semantic level vs. visual size
`as` on `Heading` sets the semantic level (`h1`…`h6`); it does not change the size. Pick the level
that matches the page outline, then set the size with `$size`.
:::

### Formatting components

`Strong` and `Em` add emphasis inside text.

  <Example.Rendered>

    <Text>This text is in <Strong>bold</Strong></Text>
  </Example.Rendered>
  <Example.Code>
    ```tsx
    <Text as="div">This text is in <Em>italics</Em></Text>
    <Text>This text is in <Strong>bold</Strong></Text>
    ```
  </Example.Code>
</Example>

## Type scale

`$size` takes a step on a 9-step scale. Each step sets the font size, line height and letter
spacing together.

      <Text $size="3">The quick brown fox jumps over the lazy dog.</Text>
      <Text $size="4">The quick brown fox jumps over the lazy dog.</Text>
      <Text $size="5">The quick brown fox jumps over the lazy dog.</Text>
      <Text $size="6">The quick brown fox jumps over the lazy dog.</Text>
      <Text $size="7">The quick brown fox jumps over the lazy dog.</Text>
      <Text $size="8">The quick brown fox jumps over the lazy dog.</Text>
      <Text $size="9" $wrap="nowrap">The quick brown fox jumps over the lazy dog.</Text>
    </Flex>
  </Example.Rendered>
  <Example.Code>
    ```tsx
    <Flex $direction="column" $gap="3">
      <Text $size="1">The quick brown fox jumps over the lazy dog.</Text>
      <Text $size="2">The quick brown fox jumps over the lazy dog.</Text>
      <Text $size="3">The quick brown fox jumps over the lazy dog.</Text>
      {/* ... */}
      <Text $size="9">The quick brown fox jumps over the lazy dog.</Text>
    </Flex>
    ```
  </Example.Code>
</Example>

:::info
`$size` also accepts any CSS size (`"1.5rem"`, `"22px"`), used as the font size instead of a scale
step. A custom size doesn't set line height or letter spacing, so set `$lineHeight` and
`$letterSpacing` yourself if you need them.
:::

## Customizing

### Type scale

The scale is made of `font-size-N`, `line-height-N` and `letter-spacing-N` tokens (N = 1…9) in the
theme:

```ts
import { createTheme, defaultTheme } from "@atomicjolt/atomic-elements";

const theme = createTheme({
  base: defaultTheme,
  variables: {
    "font-size-1": "13px",
    "line-height-1": "18px",
    "letter-spacing-1": "0em",
    // ...
  },
});
```

### Font family and weights

The default text font is [Lato](https://fonts.google.com/specimen/Lato), and icons use
[Material Icons](https://fonts.google.com/icons). Your app has to load both; see
[Installation](../Installation.mdx#2-load-the-fonts).

The font family and the four weights `$weight` maps to are theme tokens. Token values are strings:

```ts
import { createTheme, defaultTheme } from "@atomicjolt/atomic-elements";

const theme = createTheme({
  base: defaultTheme,
  variables: {
    "font-family": '"Inter", Arial, sans-serif',
    "font-weight-light": "300",
    "font-weight-regular": "400",
    "font-weight-medium": "500",
    "font-weight-bold": "700",
  },
});
```
