# Using Storybook

<a href="https://atomicjolt.github.io/atomic-libs/storybook/" target="_blank">Open Storybook</a>

[Storybook](https://storybook.js.org/) is the component reference for Atomic Elements. Every
exported component has a page there with live examples you can edit, and a full list of its props.
These docs cover the concepts that span components; Storybook covers each component in detail.

## How it's organized

The sidebar has one section per package: **Elements** for `@atomicjolt/atomic-elements`, and
**JSON Forms** for `@atomicjolt/jsonforms`. Inside **Elements**, components are grouped by
category: Layouts, Typography, Content, Inputs, Buttons, Overlays, Dropdowns, Fields, and so on.

Each component has an **Overview** page followed by one or more **stories**. A story is the
component rendered with one specific set of props, such as "Disabled" or "With error".

<img src="/atomic-libs/img/storybook-hiearchy.png" alt="The Storybook sidebar: a component with its Overview page and stories beneath it" />

## What's on an Overview page

From top to bottom:

1. **Description**: what the component is for, taken from its doc comment.
2. **Primary example**: the main story, with a **Show code** button that prints copyable JSX.
3. **Props**: every prop with its type, default and description. Event handlers are listed under
   _Events_.
4. **Style props**: for components that accept `$`-prefixed [style props](./Guides/Layout.mdx).
5. **CSS variables**: the component tokens the component reads (for example `--btn-bg-clr`), with
   their default values. Override these to restyle a component; see
   [Variants](./Guides/Customization/Variants.mdx).
6. **Stories**: the remaining examples.

## Actions

Actions log the calls a component makes to its event handlers (`onPress`, `onChange`,
`onSelectionChange`, ...), including the arguments. Use them to see exactly what a handler
receives.

## Color scheme toolbar

The toolbar has a **Color scheme** switch (Light / Dark). It sets the scheme on the
`ElementsProvider` that wraps every story, so you can check a component in both
[color schemes](./Theme/ColorSchemes.mdx).

## Running Storybook locally

From the root of the `atomic-libs` repository:

```bash
npm install
npm run storybook:dev
```

Stories live next to each component, as `ComponentName.stories.tsx` in
`packages/atomic-elements/src/components/`.
